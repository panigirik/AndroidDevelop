# AndroidDevelop

This project is an Android calculator application developed using Kotlin, Jetpack Compose, and Material 3. The main goal of the application is to demonstrate how a modern Android app can combine basic user functionality with enhanced security, cloud configuration, and push notifications using Firebase services. The application is built as a learning and demonstration project and follows modern Android development practices.

The application provides a fully functional calculator that supports basic arithmetic operations. All calculations are handled through a ViewModel following the MVVM architectural pattern, which ensures a clear separation between the user interface and business logic. The calculator also stores the history of user actions and calculations. This history can be saved locally and synchronized with Firebase Firestore, allowing the application to demonstrate interaction with a cloud database.

A key feature of the application is dynamic theming. The app supports both light and dark themes, and the visual difference between them is intentionally strong to make theme switching clearly noticeable. Backgrounds, surfaces, buttons, and text colors all change depending on the active theme. The primary color and the default theme mode are loaded from Firebase Remote Config at application startup. This allows the developer to remotely control the appearance of the app without publishing a new version. If the cloud configuration is unavailable, the app safely falls back to default theme values.

Security is implemented through a Pass Key authorization system. When the application is launched, the user must enter a previously set Pass Key to gain access to the calculator. The Pass Key is securely stored using Android’s encrypted storage mechanisms and is protected by the Android Keystore. The app requests the Pass Key every time it is opened, ensuring that access to the calculator is always protected. If the user forgets the Pass Key, they can reset it using biometric authentication such as fingerprint or face recognition. This approach combines usability with a strong level of security. After reinstalling the application, the Pass Key must be set again, which is expected behavior due to the use of secure local storage.

The application also integrates Firebase Cloud Messaging to support push notifications. On startup, the app requests notification permission on Android 13 and higher. After permission is granted, the application automatically subscribes to a predefined topic. Push notifications can then be sent to all subscribed devices directly from the Firebase Console without any additional code changes. Notifications can be sent as one-time messages or as part of Firebase Campaigns, making it easy to inform users about updates or important events. Incoming messages are handled by a FirebaseMessagingService implementation, which logs received notifications and can be extended to display system notifications.

Overall, this project demonstrates how to build a modern Android application with Jetpack Compose, apply dynamic theming controlled from the cloud, protect user access with a Pass Key and biometric authentication, store and synchronize data using Firebase Firestore, and deliver push notifications via Firebase Cloud Messaging. The project is suitable as a laboratory work, a learning example, or a small pet project that showcases practical integration of multiple Android and Firebase technologies.
